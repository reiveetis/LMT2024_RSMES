# LMT2024_RSMES
Developed during the 2024 LMT Summer Internship project.
## Radio Spectrum Management Expert System (RSMES)
This project explores the use of Generative AI and Retrieval Augmented Generation (RAG) to aid spectrum management professionals and National Regulatory Authorities work more efficiently with large amounts of technical and regulatory information. Large language models are prone to severe hallucinations, therefore they are not suitible for this kind of work on their own. RAG aims to improve LLM responses by providing contextual data, on which the model would base its answers on.
